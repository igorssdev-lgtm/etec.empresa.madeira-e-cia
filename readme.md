Como executar:
1. Coloque a pasta do projeto dentro da pasta do servidor local, por exemplo:
   - XAMPP: C:\xampp\htdocs\
   - WAMP: C:\wamp64\www\
2. Inicie o Apache.
3. Abra no navegador:
   http://localhost/IgorSouzaDaSilva_Ag3_Ds_II/
